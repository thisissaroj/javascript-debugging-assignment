# JavaScript Debugging Assignment

## Introduction
This project contains six JavaScript debugging exercises. Each program was corrected, tested, and executed using Node.js.

## Questions and Solutions

1. **Question 1 – Variable Scope:** Fixed the scope error by returning the message from the function.
2. **Question 2 – String Conversion:** Used `String()` to convert a number into a string before using `toUpperCase()`.
3. **Question 3 – Calculate Grade:** Fixed a missing closing parenthesis.
4. **Question 4 – Calculate Bill:** Fixed a missing closing parenthesis and improved input validation.
5. **Question 5 – Calculate Salary:** Corrected the spelling of the `netSalary` variable.
6. **Question 6 – Count Down:** Added a base condition to stop infinite recursion.

## Technologies Used
- JavaScript
- Node.js
- Visual Studio Code

## How to Run

Open the terminal inside the project folder and run:

```bash
node question1.js
```

Replace `question1.js` with `question2.js`, `question3.js`, `question4.js`, `question5.js`, or `question6.js` to run the other programs.
